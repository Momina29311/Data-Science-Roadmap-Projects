# Project 02 — Smart Calculator

A beginner-friendly Python calculator that performs basic arithmetic operations based on user input.

## Objective

Learn how arithmetic operators work in Python by building an interactive calculator.

## Concepts Covered

- Variables
- Input
- Data types (`int`, `float`)
- Arithmetic operators
- Type casting
- Basic output formatting

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- Supports decimal numbers
- Displays results with two decimal places

## How to Run

1. Make sure Python is installed.
2. Run the program:

```bash
python main.py
```

3. Enter two numbers and choose an operation.

## Sample Output

```txt
==== Smart Calculator ====

Enter first number: 25
Enter second number: 5

Choose an operation
1. Addition
2. Subtraction
3. Multiplication
4. Division

Enter choice: 3

Result: 25.00 × 5.00 = 125.00
```
